CinemiX — ブランド・UI 仕様（実装済みの値）
作成日: 2026-10-05 / UTF-8

■ 採用方向: A Film Contact
深いオリーブ（ink）＋淡いセージ（accent/selected）＋紙色（page/surface）。大きな欧文セリフ（Bodoni Moda）と日本語サンセリフ（Noto Sans JP）、見出しの和文は Noto Serif JP。非対称の完成見本、細い罫線、時間番号。写真が主役。
編集机ではなく、写真の見本帳をめくる感覚。均等な KPI カードや左サイドバーは使わない。

■ 色トークン（apps/web/src/styles/tokens.css）
page #F3F0E7 / surface #FFFCF4 / ink #25382E / muted #59665D / accent #D7E583 / line #C8CDC2 / selected #E2E8D7
success #315C41 / warning #805A14 / error #963E35
追加: line-strong #768078（入力・ボタン・枠など「操作対象の境界」用。下記実測により追加）
状態色だけで意味を伝えず、文言とアイコン（Notice コンポーネントの ✓ ! ✕ i）を併用。

補助 muted/page 5.29:1、muted/surface 5.88:1（合格）
CTA 文字 surface/ink 12.16:1（合格）
accent 上の ink 9.16:1、selected 上の ink 9.95:1（合格）

境界 line/page 1.42:1、line/surface 1.58:1 → UI 境界 3:1 未満。
  対応: line は罫線・区切りの装飾専用とし、入力・ボタン・枠・スイッチ等の境界は line-strong #768078（page 3.59:1、surface 3.99:1）に変更。選択状態は 2px ink 枠＋チェック表示、focus-visible は 3px ink outline＋2px offset（10.94:1）。

■ タイポグラフィ
本文: Noto Sans JP, system-ui, sans-serif / 16px / 400 / 1.6 / letter-spacing 0
補助: 13px / 500 / 1.5 / 0.01em。入力 16px 以上（iOS の自動ズーム回避）。ラベル 14px / 500 / 1.4
h1 32px / 600 / 1.15 / -0.02em（和文 Noto Serif JP）、h2 22px / 600 / 1.3 / -0.01em。大きな英字表紙（1040px 一覧の見出し）は 44px
英字見出し・ロゴ: Bodoni Moda（OFL）。Inter 一択にしない。
数字・時刻: tabular-nums（.tnum）
フォントはすべてローカル配信（public/fonts、fontsource パッケージ由来、OFL-1.1、LICENSES.txt 同梱）。

■ 余白・寸法
spacing 4/8/12/16/24/32/48。画面左右 16px、幅 430 以上で 24px。
ボタン 48px 以上、入力 48px、アイコン 22px、タップ領域 44×44 以上。
border 1px solid。radius: 入力 8px／小ボタン 8px／シート 16px／大きな見本 4px。
shadow はボトムシートのみ 0 8px 32px rgba(37,56,46,.14)。ガラス・発光・無意味なグラデーションなし。

■ 状態
hover: 精密ポインタ時のみ面色変更（@media (hover:hover) and (pointer:fine)）。active: 1px 移動のみ。
selected: 2px ink 枠＋チェック。focus-visible: 3px ink outline＋2px offset。
disabled: disabled 属性＋理由をボタン文言に（例「あと 2 点選ぶと次へ進めます」）。小さい薄灰文字に頼らない。
loading: 処理内容の文字と実進捗（フレーム数）、キャンセル可否。empty: 「まだ下書きがありません」＋作成ボタン。
success: 保存先と次操作。warning: 原因と対処。error: 再試行・素材変更・下書きに戻る。

■ レスポンシブ
320〜767: 単一カラム。768〜1023: 中央幅 600。1024 以上: 編集は中央幅 600、一覧のみ max-width 1040 で非対称の見本＋説明。PC 専用 3 ペインにしない。
100dvh、env(safe-area-inset-*)、visualViewport でキーボード表示時はプレビューを 22dvh に縮め、確定ボタンを隠さない。横向きはスクロール可、縦向き強制ロックなし。
Canvas だけの操作にせず、文字一覧・位置移動・時間入力を DOM フォームで併設。VoiceOver ラベル、キーボード操作（Enter/Space で文字選択）、prefers-reduced-motion（操作アニメーションのみ軽減、作品の演出は別）。

■ ブランド素材（apps/web/public/brand）
logo-mark.svg/png（C＋写真枠の余白、小サイズでも判別）、logo-horizontal.svg/png（CinemiX ワードマーク、末尾 X 大文字）、pwa-icon-192/512.png、apple-touch-icon.png（180）、brand-board.png（実装画面のスクリーンショットを統合したポスター型）。
すべて自作。既存 Cinemix のロゴ・配色は模倣していない。人物写真・抽象 3D なし。PNG は SVG/HTML から Chromium で書き出し（scripts/build-brand.mjs）。

■ 画面（S1〜S9）の主要コンポーネント
AppHeader（戻る・ワードマーク・保存状態）、TemplateHero/TemplateCard、SlotTile/CropSheet、PreviewCanvas（Canvas が正式結果＋DOM ハンドル）、TextSheet、AudioSheet、Notice、BottomSheet、NumberField。
