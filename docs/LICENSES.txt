CinemiX — 同梱素材・主要ライブラリのライセンス一覧
作成日: 2026-10-05

■ フォント（すべて SIL Open Font License 1.1。apps/web/public/fonts/<family>/LICENSE に原文同梱。fontsource npm パッケージ 5.3.0 から未改変の woff2 をコピー）
Noto Sans JP — Google / Noto Project — https://fonts.google.com/noto/specimen/Noto+Sans+JP
Noto Serif JP — Google / Noto Project — https://fonts.google.com/noto/specimen/Noto+Serif+JP
Caveat — Pablo Impallari ほか — https://fonts.google.com/specimen/Caveat（欧文用。和文は Noto Sans JP へ文字単位フォールバック）
Allura — TypeSETit — https://fonts.google.com/specimen/Allura（欧文用）
Bodoni Moda — Indestructible Type — https://fonts.google.com/specimen/Bodoni+Moda（UI 見出し・ロゴ用）
収録文字: fontsource のサブセット（Noto は Google Fonts の unicode-range 分割を踏襲）。絵文字は非対応（入力時に明示）。

■ 同梱サンプル画像（apps/web/public/samples/*.jpg, background-*.jpg）
CinemiX 自作の風景風図版（ImageMagick で生成した幾何図形・グラデーション）。人物なし。商用再配布可（CC0 相当として扱う）。

■ 同梱試聴用 BGM（apps/web/public/samples/cinemix-sample-bgm.mp3）
CinemiX 自作（scripts/make-sample-bgm.py で合成、約 20 秒、MP3 128kbps）。外部楽曲・楽曲カタログは使用していない。商用再配布可（CC0 相当として扱う）。

■ テンプレート表紙・見本動画（apps/web/public/templates/*/cover.png, preview.mp4）
上記サンプル素材を、アプリと同じ描画エンジン（renderFrame）で描画して生成。見本動画のエンコードのみホストの ffmpeg（libx264）。

■ ブランド素材（apps/web/public/brand）
自作。既存 Cinemix のロゴ・配色は参照していない。
